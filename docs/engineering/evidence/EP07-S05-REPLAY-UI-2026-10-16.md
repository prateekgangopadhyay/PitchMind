## Scope

The evidence disclosure now renders an observed-frame stepper from the exact frames already returned by the canonical evidence API. It validates frame identity, selected-time/sequence bounds, source hash, canonical revision, rights-review state, coordinate metadata and pitch bounds before rendering. It preserves the source pitch orientation and exposes each team’s source attack direction in a text legend. Native previous/next buttons, an announced frame counter, a data table, and the linked sequence give keyboard and non-visual alternatives. It does not interpolate between frames or change the selected match time.

Frames with absent or incomplete rights-review status are hidden. This is a conservative presentation gate, not a substitute for the outstanding source rights review. Coordinates must declare supported units and origin; candidate-feed units and football realism remain unapproved. Browser fixtures are synthetic test-only values and are not the Manu–Liverpool candidate feed.

No API contract, database, public service boundary, or architectural boundary changed, so this UI-only increment does not change the API contract or C4 diagrams.
