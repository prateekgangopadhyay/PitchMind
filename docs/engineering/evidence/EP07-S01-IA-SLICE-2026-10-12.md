## Scope and observed behavior

At the base revision, the React app rendered the entire match experience at `/` without primary navigation. When the fixture request failed, the page printed the response error and offered a full-document reload. Browser inspection on the local Vite app showed `Match service returned 500. Please retry.` The intended API contract currently fails closed with `503 MATCH_DATA_UNAVAILABLE`; the Vite-only browser run did not connect to that API host.

This slice adds a persistent six-area shell at `#/home`, `#/match`, `#/teams`, `#/players`, `#/insights` and `#/analyst`. Each route has one primary football question and a route-specific active link. Sections that have no fixture show a neutral, truthful unavailable state and a working route to check match availability. Match loading, no-fixture, and request-failure states are explicit; retry re-requests the fixture list and does not reload the page. Technical transport text is not displayed. No match/team/player/score/event/statistic or tactical copy was added. The welcome/sign-in view and seventh screen are not in this slice; other section routes are shells, not completed screen stories.

Hash routes avoid depending on an SPA fallback that the current ASP.NET host does not configure (`UseDefaultFiles` / `UseStaticFiles` only in `src/PitchMind.Api/Program.cs`). URL state survives refresh without requesting a server-side route. The skip link focuses the main landmark without changing the hash, so refreshing after skipping keeps the selected area. Route changes move keyboard focus to that area’s main question heading. Failed evidence and analyst requests retain the selected match and retry the same action endpoint; they do not reload the fixture list.

## Design and interaction review

The committed Home mockup contains illustrative live scores, club names, league standings, tactical claims and video imagery. The implementation deliberately does not reproduce them because they are not source-backed. The render reviewed at 1280×720 shows a compact brand header, persistent section navigation, the Match question and one calm availability panel; the Teams route uses the same shell and an honest empty state. The current screenshot was inspected in the local browser but no screenshot file was retained in this worktree.
