## HLD — system responsibility and architectural boundaries
**Workstream:** Platform Foundations. **Owning components / intended files:** C# / React / pipeline / local Docker.  
**Architecture pattern:** Clean Architecture / CI.  
**Design task unique to this story:** Define the supported .NET and React toolchain compatibility policy; reject domain dependency on Infrastructure/SDK by architecture tests; map every project to a C4 container.

- Honor separation: Domain pure football rules; Application use-case/ports; Infrastructure adapters; thin API; React presentation. Deviations require ADR/diagram update.
- Inputs must be synthetic, versioned, immutable and sourced through the canonical feed/ledger; no match-specific values hardcoded in C# or React. For infra/quality stories, source refs and environment/release artifacts are also versioned.
- Inputs and outputs carry `matchId, canonicalRevision, selectedTime/sequence` whenever football-related; evidence IDs/provenance where making claims. On errors return structured failure, never guess missing facts.
- Public contracts and security/role boundaries: EP01 / Azure HLD; details in [Azure HLD](../../../architecture/06-target-azure-hld.md), [Football LLD](../../../architecture/07-football-analytics-detailed-lld.md), [API](../../../api/API.md) and [Frontend](../../FRONTEND-SCREEN-CONTRACTS.md).
- Failure and scalability design: bounded memory/queue/retries, cancellation, idempotent effects and telemetry. PostgreSQL is source of truth; optional cache or AI failure cannot rewrite match state.

## Follow-up: direct internal-reference guard — 2026-10-09

Independent reviews found that direct MSBuild `Reference` items, aliases with `HintPath`, imports, packages carrying internal assemblies, caller-set `IsImplicitlyDefined` metadata, relative alias paths, and references added by `BeforeTargets=ResolveReferences` or `BeforeTargets=ResolveProjectReferences` could bypass a literal `.csproj` scan or a broad framework exception. The architecture test now evaluates MSBuild items for each source project, executes `ResolveReferences` and `FindReferenceAssembliesForReferences` to inspect target-created assembly and project references, resolved `ReferencePath` and `ReferencePathWithRefAssemblies` compiler inputs, and target-added package/framework/COM/native references, checks full project-reference paths, resolves `HintPath` values relative to the owning project before inspecting assembly identities, and inspects package compile/runtime assets for `PitchMind.*` assemblies. Domain purity allows only the `Microsoft.NETCore.App` reference defined by the active SDK's exact `Microsoft.NET.Sdk.DefaultItems.props`; negative fixtures reject forged implicit framework references, target-created framework/package references, out-of-map project references, an internal assembly added with the same Include as a baseline reference but a different HintPath, resolved-reference aliases carrying an internal assembly identity, and forged resolved-reference metadata that tries to disguise an Infrastructure binary as an allowed Application output or substitute its compiler reference assembly. SDK-generated assembly references are exempt only when they resolve under the .NET framework reference pack and their actual assembly identity is not PitchMind; SDK transitive project references are exempt only from the exact package dependency resolution target. Resolved internal assemblies are exempt only when their actual identity and exact project path match a project reachable through the documented dependency graph. Evaluation results are cached across test facts. Local Release solution build passed with 0 warnings/errors; full Release test suite passed 30 tests with 0 failures and 5 PostgreSQL integration tests skipped because no database prerequisite was available; the architecture test passed 12/12; Council validator and DAG self-test passed; `git diff --check` passed. Independent code review is complete with no remaining findings; human technical review and Product Owner acceptance remain outstanding. No architecture boundary changed, so no C4 or ADR delta was required.
