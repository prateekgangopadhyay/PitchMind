## Local implementation slice (partial; not story acceptance)
The story-packet dependency text (EP04/EP05 snapshots and insights) and the routing graph (`EP06-S01` plus `EP03-S03`) do not match. Scheduling continues to follow the routing graph as required by the execution protocol; this partial branch does not resolve or waive either gate. The canonical outbox cursor translator is a contract-bound slice, not evidence that EP03-S03 ingestion is complete.

The current local branch implements versioned `RealtimeNegotiateRequestV1`, `RealtimeNegotiateResponseV1`, and cursor-only `RealtimeCursorV1`; a local ASP.NET Core SignalR hub with authenticated, match-scoped group join/removal; role plus canonical-match existence checks; and strict `ProjectionPublishedV1` translation that discards persisted state before browser fan-out. The translator matches the emitted outbox shape (`canonicalRevision: long`, `projectionRevision: int`, and `sequence: long`), preserves the canonical revision/sequence in the cursor, and rejects malformed payloads. Negotiation uses the shared API rate limit. Local SignalR composition is enabled only for `Development` + `Runtime:Profile=local` + `Realtime:Provider=local`. Non-local profiles return `503 SIGNALR_UNAVAILABLE` until an Azure SignalR provider exists. The current `main` includes the EP06-S04 Entra/role implementation; local auth still requires configured identity or explicitly enabled Development-only header auth. The test host injects a test-only authentication handler.

The OpenAPI/API contract now specifies a positive 64-bit `clientRevision`, the local response shape, bearer authentication, 400/401/403/404/429/503 responses, cursor-only messages, and the client's responsibility to read canonical state/backfill after a sequence gap or revision change. The signal carries no score, events, insight, or projection state. Reconnect negotiation reads the current projection head and does not write match truth.

Exact local `PitchMind.Contracts.Tests` suite on the current restack candidate: 95 passed, 0 failed, 0 skipped. New S02 coverage includes cursor-only serialization from the emitted outbox JSON shape, 64-bit canonical revision preservation, malformed/extra/duplicate outbox properties, authorization on HTTP negotiation and hub handshake, local transport response, fail-closed non-local behavior, and the shared API rate limit. This does not prove actual group unsubscribe isolation, live sequence ordering/gap recovery through a connected client, outbox worker delivery, Azure SignalR negotiation, or service reconnect behavior. The Azure provider, end-to-end outbox dispatch, browser reconnect/backfill, independent review, and Product Owner acceptance remain open. No Azure operation is authorized by this implementation.
