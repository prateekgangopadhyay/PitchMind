Canonical BFF reads and local SignalR require a valid JWT bearer scheme and an operator-supplied HTTPS `Authentication:Authority`, `Authentication:Audience`, `Authentication:RoleClaimType`, `Authentication:MatchEntitlementClaimType`, and comma-separated `Authorization:ReadRoles`. Each match route also requires an entitlement claim containing the exact route match GUID. Cross-match `/canonical/fixtures` listing requires `Authorization:CatalogRoles`; an empty setting denies enumeration. Missing or malformed identity configuration fails closed. No real issuer, audience, role, or claim names are supplied in the repository.

Anonymous fixture demo routes are mapped only for Development + `Runtime:Profile=local`, return 404 outside that profile, and set `X-Data-Class: synthetic-demo`. HTTP bodies and SignalR inbound messages are limited to 4 KiB; canonical reads default to 60 requests/minute and realtime negotiation to 20 requests/minute (configurable), including direct SignalR `/hubs/matches/negotiate`. Authenticated rate-limit partitions use a lowercase SHA-256 digest of the validated `sub` claim; anonymous or subject-less traffic falls back to the connection IP. `UseRateLimiter` runs after authentication so this partition uses the authenticated principal. Concurrent SignalR connections require a positive configured cap. Subscribe and unsubscribe operations share a fixed per-connection one-minute limit (`Realtime:MaximumHubMethodCallsPerMinute`, default 30). A separate distinct active group cap (`Realtime:MaximumActiveMatchSubscriptionsPerConnection`, default 4) rejects new matches before entitlement/projection lookup when full; an already subscribed match is idempotent for the distinct cap, unsubscribe frees its slot, denied reservations are released, and disconnect clears all tracked membership. If a failed subscribe may have joined a group and cleanup cannot be confirmed, the server aborts that connection and retains its slot until disconnect cleanup. The default of four is a configurable operational resource safeguard, not a measured SLO. Connection item bookkeeping only manages SignalR group membership and does not mutate canonical match state. These controls bound repeated checks, simultaneous connections, and group accumulation on long-lived connections. CORS allows only configured origins; an empty origin list grants no browser origin. These rate defaults are safeguards, not measured throughput SLOs.
