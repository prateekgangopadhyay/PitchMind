## Local implementation contract (EP04-S04)
`IMatchProjectionReader.GetAtAsync(matchId, selectedSeconds, upToCanonicalRevision, algorithmVersion)` returns the latest immutable projection with `as_of_clock_seconds <= selectedSeconds`, `canonical_revision <= upToCanonicalRevision`, and the exact requested algorithm version. Canonical admission revision and projection revision are returned separately; selection orders by selected clock, sequence, canonical revision, then projection revision descending. An absent history returns `null`. A returned state is deserialized, re-hashed, and checked against its persisted match ID, sequence, and clock before use. `ReadEventsAtAsync` re-fetches the exact match/canonical/projection revision from PostgreSQL and validates its sequence, clock, algorithm/source metadata and state hash before using its persisted sequence and canonical revision as the event-window ceiling; it also validates each event against its indexed time/period and rejects a non-contiguous prefix. Both methods enforce the current prototype range 0..5400 seconds.

`GetMatchAtQueryService` composes the reader into an Application result containing the selected seconds, revision-pinned projection, and event window. It fails closed if the returned projection violates the requested canonical revision/algorithm/time, or if events have a mismatched match ID, non-contiguous sequence, backwards clock, or future clock. The Application query is not registered as an HTTP route. Full aggregate replay from PostgreSQL remains unavailable: the persisted `MatchEvent` payload omits `SimulationEvent` team/player/action/outcome context and the canonical store has no immutable initial-roster record.

Integration evidence uses an aggregate-built synthetic timeline with a pass at 3308 and a goal at 3309: the 3308 state/window exclude the later goal; the 3309 snapshot includes it; a revision ceiling of 2 still excludes it; repeated reads return the same state hash. A forged projection sequence is rejected after independent review. `./scripts/test-postgres.sh` passed 15/15 local PostgreSQL tests; the full solution build passed with 0 warnings/errors; the full non-isolated test run passed 55 tests with 15 PostgreSQL tests skipped (then run separately by the PostgreSQL script); the operating-model validator and `git diff --check` passed. The projection reader is infrastructure-only in this PR and is not mapped to an HTTP route. Full deterministic replay from the approved provider envelope, correction history, event/evidence payloads, authorization, and production REST/React scrubbing remain separate requirements; this change does not claim story acceptance.
