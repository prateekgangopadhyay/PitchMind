4. **Data/persistence semantics:** No match facts in UI/source; mutate canonical event/projection/outbox only in ordered transactional scope if this story writes football state. 5. **API/consumer coupling:** Update `docs/api/API.md`, typed .NET/React schema fixtures and selected-time guarantees for any exposed route; reject incompatible fields, unsupported truth classifications and unauthorized users. No direct browser access to Azure secrets or Foundry.

7. **Negative/degraded cases:** include unavailable upstream data, malformed input, cancellation, auth denial, replay before evidence and at least one non-happy-path representative of this story.

## Implemented candidate-validation slice and remaining scope
The manifest-pinned Python validator is an offline source-integrity check only. It checks the pinned bytes/hash and structural event, identity, period, raw clock-field, coordinate-number, frame, and player-metric field shape; reports raw coordinate ranges, counts, and repeatable source-order digests; and returns a blocked-for-canonicalization status. The generated [observed structural data dictionary](../../../data/MANU-LIV-OBSERVED-DATA-DICTIONARY.md) records observed field paths, JSON types/occurrence counts, null/missing counts, raw ranges, cardinalities and event-attached position-row counts. In particular, 330 event arrays have 21 rows and 1,869 have 22; this is not a time-based cadence measurement. No authoritative source-owner data dictionary was supplied. The raw `clockSeconds` values range from 0 to 5761, but the field name does not establish seconds or elapsed/period-local/stoppage-time semantics; the range is not evidence of a `96:01` display or of the required complete 90-minute fixture. A separate [measured football-data audit](../../evidence/EP03-S01-FOOTBALL-DATA-QUALITY-AUDIT-2026-10-11.md) records aggregate coordinate and metric ranges, chronology, roster-frame counts, source score snapshots, and exact-name event vocabulary comparison. These tools do not infer player identity, canonical event type, coordinate units/axes/orientation, clock/period semantics, metric definitions/units, football realism, score truth, or replay semantics. Neither feeds the application, production API, PostgreSQL, or Event Hubs. The public match API continues to return `503 MATCH_DATA_UNAVAILABLE` until a separately reviewed canonical PostgreSQL read path exists; the fictional deterministic fixture generator remains test-only. Executed evidence for the candidate-only slice is recorded in [EP03-S01 candidate validation evidence](../../evidence/EP03-S01-CANDIDATE-VALIDATION-2026-10-11.md). This slice does not meet the story's complete 90-minute fixture, football-rule review, or Product Owner acceptance criteria.
