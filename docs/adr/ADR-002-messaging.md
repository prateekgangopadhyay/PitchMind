# ADR-002 — Messaging and reliable publication
Status: Accepted design; local PostgreSQL primitives implemented in EP04-S03, transport/host integration pending.

**Decision:** Event Hubs ingests telemetry, partitioned by matchId. Service Bus transports durable background commands (explanation, recap, exports, recovery). Canonical changes and outbox rows commit in the same PostgreSQL transaction. Outbox dispatcher publishes idempotently with stable message IDs.

**Consequences:** At-least-once delivery is expected. Consumers deduplicate using stable message IDs, bound retries and isolate poison messages. EP04-S03 adds a PostgreSQL transaction port that binds aggregate updates to the persisted predecessor projection and immutable source identity, leased dispatcher state with renewal during active publish, a same-database inbox transaction, and local .NET metrics instruments. Lease renewal cancels publisher work when the database lease is lost but is not an external fencing token; an adapter must honor cancellation and consumers must deduplicate. No Service Bus/Event Hubs adapter, writer/dispatcher host registration, consumer checkpoint/order enforcement or metrics exporter is wired, and cross-system exactly-once delivery is not claimed.
