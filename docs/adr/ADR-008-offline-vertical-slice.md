# ADR-008 — Bounded offline synthetic vertical slice

Status: Superseded for current LOCAL API composition on 2026-10-10. The previously deployed DEV prototype is unchanged and remains a historical, separately owner-controlled artifact.

Problem: existing application scaffold has no durable canonical Azure implementation. Frontend/domain/API integration needs executable shared evidence without falsely claiming that infrastructure placeholders complete the product.

Decision: test projects may retain an immutable seeded golden fixture, pure selected-time projections, bounded deterministic pressing candidate and evidence-linked fallback for contract and domain tests. Production C# and React must not contain or generate match-specific values. Ordinary match reads return `503 MATCH_DATA_UNAVAILABLE` (the analyst endpoint can return `429` when rate-limited before its handler); enabling match reads requires replacing route composition with a canonical, revisioned PostgreSQL-backed read port. Registering `SyntheticMatchService` cannot enable them. The old DEV demonstration is not updated by this decision; any change to it requires exact owner approval.

Consequences: tests can exercise deterministic football rules without introducing fake canonical data into application binaries. Until a validated feed and PostgreSQL read path exist, the local UI has no match facts to display. This does not satisfy EP04-S02/S03, Azure Event Hubs, SignalR or Foundry story gates. Azure-backed implementation must use the existing application ports and preserve selected-time/score/evidence behavior from validated inputs. Never change the old prototype into a production profile through configuration aliases. Full P0 acceptance still requires PostgreSQL and actual Azure integration evidence.

Evidence: `SyntheticFixtureGenerator` has been moved to the test-only `PitchMind.TestFixtures` project. Match routes fail closed and do not resolve `SyntheticMatchService` from dependency injection. The candidate source file is owner-confirmed synthetic and redistributable, but its clock/coordinate semantics, player metrics, canonical mapping and football realism remain unresolved. This ADR records local source behavior and does not change any deployed resource.
